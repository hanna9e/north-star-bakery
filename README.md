# North Star Bakery

A four-page website for a fictional neighborhood bakery, built for Sophia's Introduction to Web Development course. It was created in Touchstone Task 2, which covers semantic HTML, styled in Touchstone 3, which covers CSS and responsive layout, and made interactive in Touchstone 4, which covers JavaScript.

- `index.html`, `products.html`, `about.html`, `contact.html`
- `css/styles.css` is a mobile-first stylesheet that uses Flexbox and media queries at 600px and 900px
- `js/storage.js` holds the shared menu data and localStorage helpers
- `js/preorder-list.js` runs the Products page pre-order list builder, with category filters and a saved list
- `js/contact-form.js` runs the contact form's JavaScript validation and fills in the saved list
- `fonts/` holds the self-hosted Lora and Nunito Sans fonts (SIL Open Font License)
- `images/` and `media/` hold the provided client assets
